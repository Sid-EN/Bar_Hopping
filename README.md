# 🍸 TAIWAN BAR BIBLE — 台灣微醺指南

全台 222 間知名酒吧的查找指南，涵蓋 20 個縣市。純靜態網頁，開檔就能用。

## 使用

直接用瀏覽器開 `index.html` 即可，不需要任何安裝或伺服器。

## 功能

**找店**
- 縣市分區頁籤（北部／中部／南部／東部離島），行政區選單隨縣市連動
- 多選標籤：酒類（複選＝符合任一種）、亮點（複選＝須全部符合），每個標籤都標示符合間數
- 篩選：聚會目的、價位、狀態（營業中／收藏／已喝過）
- 排序：獲獎優先、Google 評分、價位、店名
- 關鍵字搜尋（店名、註記、風格、獎項都能搜）
- 🔗 分享：把目前的篩選條件編進網址，貼給酒友就會看到同一份清單

**看店**
- 卡片顯示 Google 五星評分、人均消費、營業狀態、獲獎標章
- 點卡片開詳細頁：完整資訊 + 內嵌地圖 + 一鍵導航／撥號

**跑吧**
- 🕒 **現在還有開**：依當下時間判斷營業狀態，會算「還有幾小時打烊」，跨夜與公休日都處理
- 🗺️ **地圖模式**：全台撒圖釘，顏色區分獲獎／推薦／已喝過／收藏
- 🍺 **今晚路線**：選最多 8 間，自動用最近鄰排出順路的順序，一鍵開 Google Maps 多點導航
- 🍺 **今晚路線**：順序可以自己用 ‹ › 調整，也可以按「✨ 自動排序」讓它依地理位置排出最順的順序
- ❤️ **收藏與打卡**：收藏想去的店、標記已喝過並給自己的評分，附「已攻略 N/222」進度條
- 📖 **我的酒單**：點進度條或右上按鈕開啟，分「收藏／已攻略／今晚路線」三個分頁，
  可直接在清單裡移除或調整順序，並支援匯出／匯入備份
- 📱 **離線可用（PWA）**：用 GitHub Pages 之類的網址開啟後可「加入主畫面」，之後沒網路也能查
  （地圖圖磚需要連線，離線時地圖會空白）

## 檔案結構

```
index.html      畫面骨架與樣式
app.js          應用邏輯（篩選、排序、地圖、路線、酒單、營業時間解析）
data.js         酒吧資料庫 ← 要新增酒吧就改這裡
manifest.json   PWA 設定
sw.js           Service Worker（離線快取）
icons/          應用程式圖示
tools/          資料維護工具（見下）
```

> 收藏與打卡記錄存在瀏覽器的 localStorage，不會上傳到任何地方。
> 換裝置或清除瀏覽器資料就會消失，建議偶爾用「我的酒單 → 匯出備份」存一份。

## 新增或修改酒吧

編輯 `data.js`，在對應縣市段落加一行。除了 `name` 和 `city`，其他欄位都可以省略，
沒填的欄位網頁上會自動隱藏，不會留空白。

```js
{name: "店名", city: "台北市", district: "大安區", type: "經典特調", purpose: "一個人",
 style: "日式", price: 2, address: "台北市大安區某某路100號", phone: "02-1234-5678",
 hours: "週二至週日 19:00–02:00（週一休）", lat: 25.03, lng: 121.55,
 rating: 4.6, ratingCount: 320, awards: ["Asia's 50 Best Bars 2025 #40"],
 special: true, note: "自己的註記"},
```

| 欄位 | 說明 |
|---|---|
| `type` | 經典／特調／經典特調／啤酒 |
| `purpose` | 一個人／聚會／聚會或一個人 |
| `price` | 1 = NT$400–700、2 = NT$700–1,200、3 = NT$1,200 以上（金額對照可在 `data.js` 開頭的 `PRICE_TIERS` 調整） |
| `budget` | 想寫確切金額時用，例如 `"NT$500–800"`，會蓋過 `price` 的估算 |
| `hours` | 支援「週二至週日 19:00–02:00（週一休）」「20:00–02:00（週五六至03:00，週一休）」等寫法，跨夜與公休自動判斷 |
| `lat` / `lng` | 有座標才會出現在地圖上，也才能算路線距離 |
| `special` | `true` 會掛上「⭐ 私心推薦」 |
| `status` | `"CLOSED_PERMANENTLY"` 會標成已歇業並灰化 |

## 資料維護工具

需要 Node.js。

```bash
node tools/report_missing.js   # 產生「還缺哪些欄位」的檢查表（免網路）
node tools/geocode.js          # 用 OpenStreetMap 補經緯度（免費、免金鑰，約 10 分鐘）
node tools/geocode_retry.js    # 針對查無的店以店名變體重試
node tools/geocode_verify.js   # 驗證座標縣市是否正確，配錯的清掉
node tools/enrich.js           # 用 Google Places API 補評分/地址/時間（需 API 金鑰，見 tools/README.md）
```

**關於 API 金鑰**：只有 `enrich.js` 需要金鑰，用的是 **Google Maps Platform 的 Places API**。
地圖功能用的 Leaflet 與 OpenStreetMap 圖磚完全不需要金鑰。
`enrich.js` 內建 260 次查詢的硬性上限（本專案只有 222 間），超過會主動中止，不會意外燒掉免費額度。
