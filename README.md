# 🍸 TAIWAN BAR BIBLE — 台灣微醺指南

全台 222 間知名酒吧的查找指南，涵蓋 20 個縣市。

**線上版：https://sid-en.github.io/Bar_Hopping/**

沒有後端、沒有資料庫，就是一份 HTML + JS + 一個資料檔。
但透過 GitHub API，網頁上的新增與編輯會直接寫回 repo 的 `data.js`，所以它不只是唯讀的靜態頁。

## 使用

開上面的網址即可。也可以 clone 下來直接用瀏覽器開 `index.html`
（本機開檔時 PWA 離線功能不會啟用，其餘功能都正常）。

## 功能

**找店**
- 縣市分區頁籤（北部／中部／南部／東部離島），行政區選單隨縣市連動
- 多選標籤：酒類（複選＝符合任一種）、亮點（複選＝須全部符合），每個標籤都標示符合間數
- 篩選：聚會目的、價位、狀態（營業中／收藏／已喝過）
- 排序：獲獎優先、Google 評分、價位、店名
- 關鍵字搜尋（店名、註記、風格、獎項都能搜）
- 🔗 分享：把目前的篩選條件編進網址，貼給酒友就會看到同一份清單

**看店**
- 卡片顯示 Google 五星評分、人均消費、營業狀態、獲獎標章
- 點卡片開詳細頁：完整資訊 + 內嵌地圖 + 一鍵導航／撥號

**跑吧前後**
- 🕒 **現在還有開**：依當下時間判斷營業狀態，會算「還有幾小時打烊」，跨夜與公休日都處理
- 🗺️ **地圖模式**：全台撒圖釘，顏色區分獲獎／推薦／已喝過／收藏
- 📍 **離我最近**：用瀏覽器定位依距離排序，顯示「480 公尺・步行約 6 分」
- 🎲 **今晚喝哪間**：從目前篩選結果隨機抽一間，治選擇障礙
- 🍺 **今晚路線**：選最多 8 間，順序可用 ‹ › 自己調，或按「✨ 自動排序」依地理位置排出最順的順序
- ⏰ **路線時間推算**：依出發時間、每攤停留 1 小時、步行速度推算每攤抵達時間，
  **趕不上打烊的會直接標紅警告**，出發時間也可以自己改
- ❤️ **收藏與打卡**：收藏想去的店、標記已喝過並給自己的評分，附「已攻略 N/222」進度條
- 📖 **我的酒單**：點進度條或右上按鈕開啟，分「收藏／已攻略／今晚路線」三個分頁，
  可直接在清單裡移除或調整順序，並支援匯出／匯入備份
- 📝 **個人筆記與到訪紀錄**：每間店可寫心得、記錄每次到訪日期，顯示「去過 3 次・上次 2 個月前」
- 📊 **跑吧回顧**：依年份統計攻略間數、到訪次數、最常去的區域、平均給分、五星愛店
- 🖼️ **分享卡片圖**：一鍵產生單間酒吧的圖卡，可直接發到社群
- ➕ **直接在網頁新增／編輯酒吧**：填表就能改 repo 裡的 `data.js`，
  附即時驗證、卡片預覽與重複偵測，營業時間還會即時告訴你程式看不看得懂（詳見下方說明）
- ☀️ **淺色／深色主題**：預設跟隨系統，可手動切換，地圖底圖也會跟著換
- 📱 **離線可用（PWA）**：用 GitHub Pages 之類的網址開啟後可「加入主畫面」，之後沒網路也能查
  （地圖圖磚需要連線，離線時地圖會空白）

## 檔案結構

```
index.html      畫面骨架與樣式
app.js          應用邏輯（篩選、排序、地圖、路線、酒單、營業時間解析、寫回 repo）
data.js         酒吧資料庫 ← 正式資料都在這，網頁上的新增/編輯最後也是寫進這個檔
manifest.json   PWA 設定
sw.js           Service Worker（離線快取）
icons/          應用程式圖示
tests/          測試（npm test）
tools/          資料維護工具（見下）
```

`app.js` 開頭有幾個可以直接調整的常數：

| 常數 | 用途 |
|---|---|
| `GH_DEFAULT_REPO` | 預設要寫回哪個 repo |
| `GH_TOKEN_EXPIRY` | 畫面上顯示的權杖到期日，換權杖時要一起改 |
| `MAX_ROUTE` | 今晚路線最多幾攤（目前 8） |
| `STAY_MINUTES` / `WALK_KMH` | 路線時間推算用的每攤停留時間與步行速度 |

`data.js` 開頭的 `PRICE_TIERS` 則是價位級距對應的實際金額。

> 酒吧資料一律存在 repo 的 `data.js`，是所有人共用的正式資料。
> 只有**收藏、打卡、個人筆記、今晚路線**存在瀏覽器的 localStorage，不會上傳。
> 換裝置或清除瀏覽器資料就會消失，建議偶爾用「我的酒單 → 匯出備份」存一份。

## 新增或修改酒吧

按右上角的「➕ 新增酒吧」新增，或在任何一間店的詳細頁按「✏️ 編輯資料」修改。

### 🚀 儲存並寫回 repo

直接透過 GitHub API 把資料 commit 進 `data.js`，Pages 約一分鐘後更新，所有人都會看到。
畫面會立刻反映變更，不必等部署完成。

編輯模式下還有「🗑️ 從 repo 刪除」，會把那一行從 `data.js` 移除。

第一次使用要先設定連線，之後就不用再碰了 → [存取權杖設定](#存取權杖personal-access-token)。

### 📋 複製 data.js 格式

不想設定權杖的話，按這顆會複製一行可直接貼進 `data.js` 的程式碼，自己貼上再 commit 即可。

### 直接編輯 data.js

在對應縣市段落加一行。除了 `name` 和 `city`，其他欄位都可以省略，
沒填的欄位網頁上會自動隱藏，不會留空白。改完可以跑 `npm run validate` 確認格式正確。

```js
{name: "店名", city: "台北市", district: "大安區", type: "經典特調", purpose: "一個人",
 style: "日式", price: 2, address: "台北市大安區某某路100號", phone: "02-1234-5678",
 hours: "週二至週日 19:00–02:00（週一休）", lat: 25.03, lng: 121.55,
 rating: 4.6, ratingCount: 320, awards: ["Asia's 50 Best Bars 2025 #40"],
 special: true, note: "自己的註記"},
```

| 欄位 | 說明 |
|---|---|
| `type` | 經典／特調／經典特調／啤酒 |
| `purpose` | 一個人／聚會／聚會或一個人 |
| `price` | 1 = NT$400–700、2 = NT$700–1,200、3 = NT$1,200 以上（金額對照可在 `data.js` 開頭的 `PRICE_TIERS` 調整） |
| `budget` | 想寫確切金額時用，例如 `"NT$500–800"`，會蓋過 `price` 的估算 |
| `hours` | 支援「週二至週日 19:00–02:00（週一休）」「20:00–02:00（週五六至03:00，週一休）」「每日 18:00–02:00」「週一到週五…」等寫法；「周」「週」通用，跨夜與公休自動判斷。在網頁表單裡填會即時顯示解析結果 |
| `lat` / `lng` | 有座標才會出現在地圖上，也才能算路線距離 |
| `special` | `true` 會掛上「⭐ 私心推薦」 |
| `status` | `"CLOSED_PERMANENTLY"` 會標成已歇業並灰化 |

## 重複資料怎麼防

多人共用或自己重複送出時，有四道防線：

- 店名比對會**正規化**（忽略大小寫、空白與標點），
  「Bar Weekend」「BAR  Weekend」「Bar-Weekend」視為同一間
- 送出前會**重新抓一次 repo 上最新的 `data.js`** 再檢查，
  所以別人在你開啟頁面之後新增的店也擋得到
- 真的重複時會跳出確認，讓你選擇覆蓋或取消，不會默默產生兩筆
- 寫入時同名同縣市一律**取代**該行，不會新增第二行

`npm run validate` 與 CI 也會用同一套規則把關。

其他寫入行為：
- 若剛好有人同時改了 `data.js`（sha 衝突），會自動重抓最新版再試一次
- 編輯時把縣市改掉的話，會先刪掉舊行再插進新縣市的段落
- 改名時，你本機的收藏、打卡、筆記、路線會跟著搬到新名字

## 存取權杖（Personal Access Token）

「寫回 repo」是靠 GitHub 的 Contents API 完成的，所以需要一把有寫入權限的權杖。
目前使用中的權杖 **有效期至 2027/09/01**。

### 產生一把新的權杖

1. GitHub → 右上角頭像 → **Settings**
2. 左側最下方 **Developer settings**
3. **Personal access tokens → Fine-grained tokens**
4. 按 **Generate new token**，然後：

   | 設定項目 | 要選什麼 |
   |---|---|
   | Token name | 隨便取，例如 `bar-bible-web` |
   | Expiration | 自己決定（目前這把設一年） |
   | Repository access | **Only select repositories** → 只勾 `Bar_Hopping` |
   | Permissions → Repository permissions | 只把 **Contents** 設為 **Read and write**，其餘全部保持 No access |

5. 按 Generate token，**複製顯示出來的那串**（離開頁面後就再也看不到了）

> 只給 Contents 權限是刻意的。權杖萬一外流，對方最多只能改這一個 repo 的檔案，
> 動不到你其他 repo，也改不了帳號設定。

### 填進網站

1. 打開網站 → 右上角 **➕ 新增酒吧**
2. 展開表單下方的 **⚙️ 連線設定**
3. Repository 保持 `Sid-EN/Bar_Hopping`，把權杖貼進「存取權杖」欄位
4. 按 **儲存設定**，再按 **測試連線** 確認顯示「連線正常」

設定一次就好。之後這個區塊會自動收合並顯示「✓ 已連線」，直接按「🚀 儲存並寫回 repo」即可。
欄位不會回填權杖原文，只會顯示遮蔽字元與末四碼供辨認。

### 更換或撤銷權杖

- **更換**：直接在同一個欄位貼上新的權杖，按「儲存設定」即可覆蓋
- **從這台電腦移除**：按「清除權杖」（只清瀏覽器，GitHub 上那把還有效）
- **真正撤銷**：到 GitHub 的 Fine-grained tokens 頁面把它 **Delete**。
  權杖一旦外流（貼到聊天室、截圖、commit 進程式碼）就一定要走這步，光清瀏覽器沒有用

### 換權杖後要順手改的地方

畫面上顯示的到期日寫在 [`app.js`](app.js) 最上方的常數，換權杖時記得一起更新：

```js
// app.js
const GH_TOKEN_EXPIRY = '2027-09-01';   // 改成新權杖的到期日，格式 YYYY-MM-DD
```

到期前 30 天，畫面上的日期會轉成警告色；過期後會變紅字提醒更換。
不想顯示到期日就設成空字串 `''`。

### 安全須知

> ⚠️ 權杖以**明文存在瀏覽器的 localStorage**。能操作這台電腦的人就拿得到，
> 所以共用或公用電腦請不要儲存，用完按「清除權杖」。
>
> ⚠️ **絕對不要把權杖寫進 `app.js`、`index.html` 或任何原始碼。**
> 這個網站是公開的，任何人都能直接下載 `app.js` 讀到內容；
> 而且 commit 進 git 之後會永久留在歷史裡，刪掉也追不回來。
> 實務上 GitHub 的 secret scanning 也會偵測到並自動撤銷。
> `npm test` 會掃描原始碼有沒有形似權杖的字串，防止不小心寫死。


## 開發

```bash
npm install     # 只有測試需要 jsdom
npm test        # 資料校驗 + 功能測試 + PWA 檢查（共 272 項）
npm run validate  # 只跑資料校驗，不需要任何套件
```

每次 push 與 PR 都會由 GitHub Actions 自動跑上述測試。

## 部署

已部署在 **https://sid-en.github.io/Bar_Hopping/**，每次推上 `main` 由
`.github/workflows/pages.yml` 自動更新。

PWA 的離線功能需要 https 網址才會生效，用 `file://` 直接開檔案不會註冊 Service Worker。

## 資料維護工具

需要 Node.js。

```bash
node tools/report_missing.js   # 產生「還缺哪些欄位」的檢查表（免網路）
node tools/geocode.js          # 用 OpenStreetMap 補經緯度（免費、免金鑰，約 10 分鐘）
node tools/geocode_retry.js    # 針對查無的店以店名變體重試
node tools/geocode_verify.js   # 驗證座標縣市是否正確，配錯的清掉
node tools/enrich.js           # 用 Google Places API 補評分/地址/時間（需 API 金鑰，見 tools/README.md）
```

**關於 API 金鑰**：只有 `enrich.js` 需要金鑰，用的是 **Google Maps Platform 的 Places API**。
地圖功能用的 Leaflet 與 OpenStreetMap 圖磚完全不需要金鑰。
`enrich.js` 內建 260 次查詢的硬性上限（本專案只有 222 間），超過會主動中止，不會意外燒掉免費額度。
